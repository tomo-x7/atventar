# フォームコンポーネント

作成・編集・参加・記事登録・アカウント操作を、Storybook 内で独立して確認するための UI です。
ルーティング、認証、API、永続化は実装していません。

`onSave`、`onDelete`、`onWithdraw` などは同期コールバックです。送信・削除後の表示はローカルの UI 状態で、サーバーでの成功を保証しません。接続時には非同期処理の成功・失敗と表示状態を連動させてください。`isSubmitting` と `error` で送信中とエラーを表示できます。

CalendarForm の編集時は現在の枚数未満にできません。個別のカレンダー削除は管理 UI から行います。
