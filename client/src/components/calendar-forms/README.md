# フォームコンポーネント

カレンダー作成・編集、参加・記事登録、ログインを Storybook 内で独立して確認する UI です。
ルーティング、認証、API、永続化は実装していません。

`onSave` と `onWithdraw` は同期コールバックです。送信・参加取消後の表示はローカルの UI 状態で、サーバーでの成功を保証しません。接続時には非同期処理の成功・失敗と表示状態を連動させてください。`isSubmitting` と `error` で送信中とエラーを表示できます。

CalendarForm の `currentYear` はサーバーの権威時刻から渡す必須値です。新規作成はこの年を使用し、編集は `initialValue.year` を保持します。年と枚数の入力はありません。カレンダー全体削除の UI もありません。

参加前は登録先の枚が未確定のため、EntryForm は日付だけを表示します。編集時には確定済みの枚番号を表示できます。

EntryForm の「書く内容」は参加時から公開するタイトルで、必須です。記事 URL は参加時に未入力でも登録できます。参加取消は本人用の UI で、主催者による参加者操作には使用しません。
