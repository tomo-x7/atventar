# client

React + TypeScript + Vite のクライアントです。
セットアップは[ルートの README](../README.md)を参照してください。

```sh
pnpm storybook       # http://localhost:6006
pnpm build-storybook # storybook-static に出力
pnpm build
pnpm lint
```

## コンポーネント

`src/components/index.ts` から UI と型を公開しています。CSS は各コンポーネントで読み込むため、アプリのグローバル CSS は不要です。

| ディレクトリ | UI |
| --- | --- |
| `advent-calendar` | 複数枚のカレンダー、参加時の書く内容、公開記事、本人の登録編集、モバイルの日付別リストと枚数切り替え |
| `calendar-directory` | 一覧、検索、年選択、並べ替え、追加表示、過去年、ユーザーの参加・主催・記事 |
| `calendar-forms` | カレンダー作成・編集、参加・記事登録・本人による参加取消、ログイン |
| `service-shell` | ヘッダー、ログイン状態、ヘルプ、読み込み中、取得エラー、見つからない状態 |

Storybook の各画面は独立しています。既存の `App.tsx` は変更せず、API・認証・永続化・ルーティングは追加していません。選択や保存はコールバックで受け取ります。フォームの状態制御については[フォームの README](src/components/calendar-forms/README.md)を参照してください。

## カレンダーと参加登録

`CalendarCollection` の `sheets: CalendarSheet[]` に、サーバーから受け取った各枚の `id`、自動連番の `number`、1〜25日の `entries` を渡します。各枚の名前・サブタイトルはありません。UI に枚数の追加・変更・削除の操作はありません。

埋まっている日にも参加でき、`onJoin(day)` には希望日だけを渡します。必要な追加枠の生成と、どの枚に登録するかの決定はサーバー側の責務です。この UI は追加枠の生成・振り分け・定員判定を実装しません。登録が25件ある枚があっても、企画への参加は続けられます。

参加登録の `title` は、参加時点から公開する「書く内容」です。公開前でも表示し、URL は `published` の記事だけリンクにします。登録の `isOwner` はログイン本人の登録にのみ設定し、その枠にだけ編集ボタンを表示します。参加の解除は本人の編集フォームから行います。カレンダー作成者に他の参加者の登録を変更・解除する UI はありません。プロフィール設定 UI もありません。

カレンダーの作成年は入力できません。`CalendarForm.currentYear` にサーバーの現在年を渡します。端末の時計は使いません。編集時は元のカレンダーの年を保持します。サーバー側での作成年の検証は接続時に実装してください。

PC・モバイルとも上部の連番で表示する枚を切り替えます。PC は左に日付・ユーザーアイコンだけのカレンダー、右に書く内容と操作の一覧を配置し、モバイルではカレンダーを上、一覧を下に配置します。カレンダーの日付を選ぶと該当する一覧行へ移動し、キーボードのフォーカスも移ります。

参加者の `authorAvatarUrl` を指定すると、カレンダーと一覧の両方にアイコンを表示します。未指定・読込失敗時は表示名の先頭文字を表示します。サンプルのアイコンはローカル生成の架空のデータで、外部画像サイトには接続しません。

Storybook には空・登録済みの日・長文・モバイル・送信中・エラーを含めています。`play` で検索、埋まった日への参加選択、本人の編集、保存、参加取消などを確認でき、a11y addon でアクセシビリティを検査できます。

画面構成の参考: [Adventar](https://adventar.org/)、[過去のカレンダー](https://adventar.org/archive)、[ヘルプ](https://adventar.org/help)。サンプルのカレンダー・参加者・記事は架空のデータです。

lint・format はルートの Biome 共通設定を使います。`pnpm dev` / `pnpm preview` は既存の Vite アプリを起動します。今回の UI は `pnpm storybook` で確認してください。

UI は白・黒・グレーを基調とし、ユーザーアイコンは丸く表示します。公開済みの記事がある日付セルには折り返した紙の角を付け、参加予定や公開待ちには付けません。
